# Mitwirken

Beiträge für nichtkommerzielle Zwecke sind willkommen. Mit einem Beitrag bestätigst du, dass du ihn unter der Projektlizenz bereitstellen darfst.

1. Issue mit Problem und gewünschtem Verhalten anlegen.
2. kleinen, fokussierten Branch erstellen.
3. Tests für neue Fachlogik ergänzen.
4. `npm test`, `npm run typecheck`, `npm run lint` und `npm run build` ausführen.
5. Pull Request mit Sicherheits- und Migrationsauswirkungen beschreiben.

Committe niemals echte Kontoauszüge, API-Schlüssel, `.env`-Dateien oder personenbezogene Daten. Import-Fixtures müssen vollständig synthetisch sein.
